# Security Policy

## Reporting Security Issues

Security reports for NMQ should reach the maintainer of
[alshawshfras3-cmd/nmq](https://github.com/alshawshfras3-cmd/nmq). The repository
owner is [alshawshfras3-cmd](https://github.com/alshawshfras3-cmd).

If GitHub shows **Report a vulnerability** in this repository's Security tab,
use that private reporting flow. Its availability depends on the repository's
settings; this policy does not imply that private reporting is enabled.

Otherwise, use a private contact method published on the owner's profile. If
none is available, open a minimal issue in this repository asking the maintainer
for a private reporting channel. Include only that request, with no vulnerability
details, affected accounts, tokens, or other sensitive information. Share the
report below after a private channel has been established.

## What to Include in Your Report

In your private report, include as much of the following information as possible:

- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue
